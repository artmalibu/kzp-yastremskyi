# Консольний застосунок обробки туристичних маршрутів (Варіант 26)

Цей проєкт призначений для зчитування, валідації та обчислення підсумкових показників про туристичні маршрути з CSV-файлу.

## Структура та модель даних (Лабораторна робота №2)

У цій версії реалізовано об'єктно-орієнтовану модель предметної області:
- **`Route`** — незмінний клас-сутність із перевіркою інваріантів (назва, довжина > 0 км, набір висоти >= 0 м, складність 1-5, тривалість > 0 днів).
- **`RouteSummary`** — `record` для зберігання підсумкових 4 показників варіанта.
- **`RouteController`** — контролер для керування читанням, валідацією та звітністю.
- **`ArgsParser`** — парсер аргументів командного рядка.
- **`AppVersion`** — клас автоматичного зчитування версії з `pom.xml`.
