# Консольний продукт: Обробка даних про туристичні маршрути (Варіант 26)

## Призначення
Програма зчитує CSV-файл із записами про туристичні маршрути, валідує їх, обчислює 4 ключові показники варіанта та виводить форматований звіт у консоль і файл `out/report.txt`.

## Формат вхідних даних (`data/input.csv`)
Записи розміщуються по одному в рядку, поля розділяються крапкою з комою `;`. Кодування файлу: UTF-8.
Порядок полів:
`name` (String); `lengthKm` (double); `elevationM` (int); `difficulty` (int); `days` (int)

**Приклад:**
```csv
Чорногірський хребет;55.5;2050;4;3
Мармароси;42.0;1600;3;2
