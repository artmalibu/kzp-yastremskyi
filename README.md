# Консольний застосунок обробки туристичних маршрутів (Варіант 26)

Цей проєкт призначений для зчитування, валідації та обчислення підсумкових показників про туристичні маршрути з CSV-файлу.

## Архітектура та об'єктна модель (Версія 1.3.0 — Лабораторна робота №3)

У поточній версії реалізовано розширювану ієрархію класів предметної області на основі наслідування та поліморфізму:
- **`Route`** — абстрактний запечатаний (`abstract sealed`) базовий клас туристичного маршруту зі спільною перевіркою інваріантів, `equals`/`hashCode` та поліморфним методом `calculateComplexityScore()`.
- **`RouteKind`** — перелічуваний тип (`enum`) видів маршрутів: `HIKING` («піший») та `CYCLING` («велосипедний»).
- **`HikingRoute`** — підтип пішого маршруту з додатковою ознакою потреби супроводжуючого провідника (`guideRequired`) та власною формулою складності.
- **`CyclingRoute`** — підтип велосипедного маршруту з додатковою ознакою типу покриття (`pavedSurface`) та власною формулою складності.
- **`RouteSummary`** — незмінний `record` для зберігання підсумкових 4 показників варіанта.
- **`RouteController`** — контролер для керування читанням, валідацією та звітністю.
- **`ArgsParser`** — парсер аргументів командного рядка (`--help`, `--version`, `--input`, `--output`).
- **`AppVersion`** — клас автоматичного зчитування версії продукту з `pom.xml`.

## Команди збірки та запуску

Збірка та запуск виконуються через Maven Wrapper:

```powershell
# Збірка, модульні тести JUnit 5, аналіз SpotBugs та пакування JAR
.\mvnw.cmd clean verify package

# Перевірка версії зібраного артефакту
java -jar target/kzp-yastremskyi-1.3.0.jar --version

# Запуск застосунку зі стандартними параметрами (data/input.csv -> out/report.txt)
java -jar target/kzp-yastremskyi-1.3.0.jar
