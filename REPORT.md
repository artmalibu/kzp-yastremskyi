# Звіт до лабораторної роботи № 1

## 1. Тема і варіант
- Тема: Розгортання Java-проєкту та базова обробка даних
- **Предметна область:** Туристичні маршрути
- **Номер варіанта:** 26
- **Операційна система:** Windows 10/11 (з перевіркою CI на Ubuntu, macOS та Windows)

## 2. Мета роботи
Пройти повний шлях від створення репозиторію та налаштування CI/CD інфраструктури до консольної програми, яка відтворювано збирається та тестується на Windows, macOS та Ubuntu.

## 3. Постановка задачі
Розробити консольну програму для обробки файлу `data/input.csv` (UTF-8, роздільник `;`).
Структура запису: `name` (String); `lengthKm` (double); `elevationM` (int); `difficulty` (int); `days` (int).

**Обчислювані показники (Варіант 26):**
1. Кількість коректних записів.
2. Середня довжина маршрутів (км).
3. Максимальний набір висоти (м).
4. Сумарна тривалість (днів).

## 4. Структура програми
- `ua.lviv.iot.Main` — головний клас, обробка CLI-аргументів, бізнес-логіка валідації та розрахунку показників.
- `ua.lviv.iot.FileReport` — допоміжний клас для кросплатформного читання та запису UTF-8 файлів через `java.nio.file.Path`.
- `ua.lviv.iot.MainTest` — модульні тести JUnit 5.

## 5. Інфраструктура
- **Система збірки:** Maven 3.x через Maven Wrapper (`mvnw` / `mvnw.cmd`).
- **Тестування:** JUnit 5 (версія 5.10.2).
- **Статичний аналіз:** SpotBugs Maven Plugin.
- **Пакування:** Maven Shade Plugin (виконуваний fat-JAR із маніфестом).
- **CI/CD:** GitHub Actions з матрицею на `ubuntu-latest`, `windows-latest`, `macos-latest` та публікацією артефактів.
